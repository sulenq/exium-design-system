## 1. Quality Check (QC) — 24 November 2026

Semua item **Need Fixing** (Toast engine, ToastStack, ToastItem) sudah selesai. Hasil QC menyeluruh untuk 160 komponen ada di dokumen audit TernaQin (tab _Quality Check_). Status **Done** hanya diberikan ke komponen yang seluruh temuan QC-nya sudah ditutup; komponen yang masih punya temuan tetap di status lamanya dengan catatan `Open:`.

**Cross-cutting fix (berlaku untuk semua komponen):**

| Area           | Perubahan                                                                                                                                                                                                                                                                                                                           |
| :------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reduced motion | `prefers-reduced-motion: reduce` di `globalCss` mematikan animasi & transisi (Dialog, Drawer, Toast, Skeleton, Menu, Popover, TopBarLoader).                                                                                                                                                                                        |
| Touch target   | Button recipe menambah `::after` di `@media (pointer: coarse)` sehingga hit area minimal 48 × 48 px tanpa mengubah ukuran visual maupun layout. Berlaku ke semua Button, IconButton, dan CloseButton.                                                                                                                               |
| Contrast       | Semantic token `fg.muted/subtle/error/warning/success/info` dan `green/orange/red/blue` (`fg`, `solid`, `contrast`) diset ≥ 4,5 : 1 di light mode. Nilai `base` memakai `!important` karena kondisi `_light` bawaan Chakra (`:root`) lebih spesifik daripada `base` (`:where(html)`). Dijaga oleh `chakra-system.contrast.test.ts`. |
| i18n           | ±100 string hardcode dipindah ke Paraglide (`translations/id.json`, `en.json`).                                                                                                                                                                                                                                                     |
| Test           | Render helper `src/test/render.tsx`, matcher vitest-axe, test unit (date utils, countdown, toast manager), test komponen + axe (Button, Badge, Field, PinInput, Snackbar, DatePicker), dan test regresi contrast.                                                                                                                   |
| Docs           | Page baru: DatePicker, CloseButton, ToggleTip, Url, FormatNumber, Snackbar.                                                                                                                                                                                                                                                         |
| Path header    | Komentar path baris pertama di `src/design-system` disinkronkan (`generate-file-path-header`).                                                                                                                                                                                                                                      |

**Follow-up QC (PR berikutnya):** contrast dark mode diuji di 88 pasangan warna (semua lolos), Tooltip long-press di touch device, CommonAppShell layout mobile, error typecheck `Modal size="5xl"` (penyebabnya type Chakra yang basi; `typecheck` kini menjalankan `chakra typegen`), decouple Map dari app GIS lama (component dedicated IGT dihapus), sapuan i18n kedua, dan 45 docs page baru dengan sidebar yang dikelompokkan ulang (satu kategori per group, tanpa "&").

**Primitive baru (Wave 1–3 roadmap TernaQin):** CurrencyInput, QrScanner, CameraCapture, PrintLayout, dan TreeView, plus hook `useExchangeRate`, `usePrint`, dan `useCameraStream`. DocumentViewer tidak dibuat; PDF dibuka di viewer bawaan browser.

**Masih open:** touch target tetap hit area 48 px tanpa mengubah ukuran visual (keputusan desain); label dan deskripsi pilihan basemap belum di-i18n; test di device sungguhan (HP, screen reader) belum dilakukan.
